# Marketplace listing copy (maina888)

**Name:** SMS via Africa's Talking
**Tagline:** Order SMS, bulk sends, quiet hours and delivery reports through Africa's Talking.
**Category:** Notifications / Marketing
**Price:** Free (MIT)
**Compatibility:** Botble CMS core 7.3.0+, PHP 8.2+, any theme; Ecommerce plugin optional

**Short description**
Send SMS from Botble through Africa's Talking. Customers get order messages you can switch on and edit, you can text one number, every customer or a pasted list, and every message is logged with its delivery status and cost. Quiet hours keep bulk messages out of the night.

**Highlights**
- Order placed, confirmed, payment received and completed SMS with editable text
- Bulk sends to all customers or a pasted list, personalised with {{first_name}}
- Quiet hours for non-urgent messages, in your timezone
- Delivery reports, cost per message and one-click resend in the SMS logs
- Sandbox and Live, account balance and test send on the settings page
- API key stored encrypted
- Developer API (sms_send, templates and audiences filters, events), used by the WhatsApp plugin's SMS fallback
- Clean uninstall, no extra Composer packages
